# ÁvilaOS

Proyecto 1 de Sistemas Operativos: simulador de sistema operativo distribuido.

Requiere JDK 25 y Apache NetBeans. El desarrollo sigue el [diseño aprobado](docs/superpowers/specs/2026-10-18-avilaos-design.md) y la [hoja de ruta](docs/superpowers/plans/2026-10-19-avilaos-roadmap.md).

## Verificación

Seleccionar JDK 25 y ejecutar `mvn test`. Las pruebas son ejecutables Java con comprobaciones propias; no requieren JUnit ni habilitar assertions con `-ea`.

Este repositorio contiene trabajo en desarrollo. El primer módulo prepara estructuras y modelo; todavía no implementa la simulación completa.
